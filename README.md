## How I ship

```text
Idea / Product problem
        ↓
Issue / Scope
        ↓
Branch + implementation
        ↓
Pull Request
        ↓
CI + validation + evidence
        ↓
Merge
        ↓
Exact-SHA version tag
        ↓
GitHub Release
        ↓
Production / public artifact
```

I prefer **observable engineering progress** over local-only progress: releases, evidence, and product milestones should be discoverable from the repository history.
